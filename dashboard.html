Local AI reasoning

Power page analysis, chat, writing assistance, definitions, study tools and selected-text actions with one shared on-device model.

ON DEVICE

Uses WebLLM to run Qwen 2.5 1.5B Instruct (4-bit) in a dedicated WebGPU worker. The model is tuned for a 2K context to balance stronger answers with integrated-GPU memory. Model files are cached by your browser; prompts and answers stay on this device. An internet connection is needed for the first download. No paid API key or AI server is used.

Privacy by design

What happens to your browsing data.

LOCAL ONLY

ORACLE has no ORACLE server, analytics, accounts, or paid AI API keys. Optional Local AI uses WebLLM and a model hosted for download by MLC/Hugging Face; only model files are downloaded. Prompts, supplied page text and generated answers are processed locally by WebGPU in your browser, not sent to an AI server. The dictionary can make its separately documented word-only lookup when enabled.

Permissions & data

Why access is needed, and how to clear your information.

View permission explanations
  • storage — saves your chat, vault, bookmarks, settings and the writing assistant’s autosaved draft locally.
  • tabs — lists, searches, switches and closes tabs, and finds duplicates. ORACLE reads tab titles and addresses only for this.
  • activeTab + scripting — lets ORACLE read a tab you had open before installing it, when you click the toolbar icon.
  • Access to http/https pages (content script) — needed to read page text for analysis, show the selection button and highlight matches. Nothing is sent anywhere.

About ORACLE

A private browser companion, built to work offline.

VERSION 1.6.0

ORACLE uses one shared on-device Qwen model for generated analysis, writing assistance, explanations, summaries, revision notes, facts, flashcards, quizzes and selected-text tools. Exact browser operations and dictionary retrieval remain local and deterministic, with dictionary entries supplied to the model when a deeper explanation is requested.
