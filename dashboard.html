Local AI reasoning

Give ORACLE a language model for open-ended questions and explanations.

ON DEVICE

Uses Chrome’s built-in Gemini Nano model. Chrome downloads the model once; answers are then generated on your device. No paid API key, AI server, or new extension permission is needed. The first setup requires internet access and a supported computer.

Checking Chrome’s local AI support…
Requires a recent version of Google Chrome and compatible hardware. If unavailable, ORACLE’s existing tools continue to work.
◈

Privacy by design

What happens to your browsing data.

LOCAL ONLY

ORACLE has no ORACLE server, analytics, accounts, or paid AI API keys. Optional Local AI uses Chrome’s built-in on-device model; prompts and supplied page text are processed locally by Chrome, not sent to an AI server. The dictionary can make its separately documented word-only lookup when enabled.

Permissions & data

Why access is needed, and how to clear your information.

View permission explanations
  • storage — saves your chat, vault, bookmarks and settings locally.
  • tabs — lists, searches, switches and closes tabs, and finds duplicates. ORACLE reads tab titles and addresses only for this.
  • activeTab + scripting — lets ORACLE read a tab you had open before installing it, when you click the toolbar icon.
  • Access to http/https pages (content script) — needed to read page text for analysis, show the selection button and highlight matches. Nothing is sent anywhere.

About ORACLE

A private browser companion, built to work offline.

VERSION 1.0.4

ORACLE combines deterministic page tools with optional on-device Local AI. The local model can answer open-ended questions and explain concepts; page summaries, facts, dictionary lookups and study tools continue to use ORACLE’s existing local processing.
